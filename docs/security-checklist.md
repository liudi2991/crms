# CRMS 上线前安全自查清单（补充）

本清单与 [deploy/SECURITY.md](../deploy/SECURITY.md) **配合使用**：前者侧重 **运维与密钥**，本文侧重 **验收评审时的条目化勾选**。

---

## 1. 身份与访问

| # | 检查项 | 结论 |
| --- | --- | --- |
| 1.1 | 生产环境已禁用默认/弱口令；`admin` 仅必要时启用且强密码 | □ |
| 1.2 | JWT/会话由 HTTPS 传输；Cookie 标志（如 `Secure`）符合环境 | □ |
| 1.3 | 普通用户无法访问用户管理、系统参数、回收站硬删等管理接口（抽查 RBAC） | □ |
| 1.4 | 数据范围：销售账号仅能访问授权范围内客户/合同（与 SRS 一致） | □ |

## 2. 密钥与配置

| # | 检查项 | 结论 |
| --- | --- | --- |
| 2.1 | `MYSQL_*`、`MINIO_*`、`CRMS_AES_KEY` 等已按 SECURITY.md 轮换 | □ |
