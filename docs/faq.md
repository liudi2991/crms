# CRMS 常见问题（FAQ）

面向用户与一线运维，回答高频问题。接口与字段细节见 [OpenAPI](./openapi.yml)。

---

## 登录与账号

**问：首次登录后不让进系统，一直跳到改密码页。**  
答：种子管理员开启了「强制改密」。在「修改密码」完成符合强度要求的密码后即可访问业务菜单。

**问：提示账号锁定。**  
答：短时间内失败次数过多会锁定约 15 分钟；或由管理员在「用户管理」中解锁（若已实现）。

**问：复制进去的密码明明对，仍提示错误。**  
答：检查是否有多余空格、键盘输入法全角符号；确认连接的是正确环境（测试/生产 URL 勿混用）。

---

## 权限与数据范围

**问：我能看到别人部门的客户吗？**  
答：取决于角色与 **数据范围**（本人 / 本部门 / 全公司）。看不到是预期行为。

**问：菜单点了提示 404。**  
答：当前账号 **无该路由权限**（或菜单未授权）。联系系统管理员分配权限点。

---

## 业务操作

**问：为什么不能删除某条回款记录？**  
答：按设计，实际回款通常 **不可物理删除**，错误录入可通过 **红冲** 纠正（需财务侧权限）。

**问：回收站里选类型报错「不支持的回收站类型」。**  
答：列表查询参数 `bizType` 须为大写：`CUSTOMER`、`CONTRACT`、`PAYMENT_RECORD`（见后端回收站接口）。

**问：合同状态改不了。**  
答：状态机只允许规定的迁移（如草稿可到履行、终止等）。不符合规则的迁移会被拒绝。

## 环境与运维

**问：接口返回 401。**  
答：Token 过期或未登录；重新登录。若走 Nginx，确认反向代理未剥离 `Authorization` 头。

**问：附件上传失败。**  
答：检查 MinIO 是否可达、桶是否创建、文件大小与类型是否符合 SRS 限制。

**问：上传超大文件直接报 `SYS-500` 系统错误？**  
答：v1.0.5 起会准确返回 `FL-003 文件大小超出限制`（HTTP 413）。如果仍是 `SYS-500`，确认服务版本 ≥ v1.0.5（含 [GlobalExceptionHandler](../crms-app/src/main/java/com/company/crms/common/exception/GlobalExceptionHandler.java) 对 `MaxUploadSizeExceededException` 的处理）。

**问：合同附件传到第 11 个就被拒绝？**  
答：早期版本硬编码上限为 10。v1.0.5 已改成系统参数 `contract.attachment.max_count`（默认 20）。管理员可在「系统管理 → 系统参数」调整，**实时生效**。

**问：要切换到 MinIO 怎么改？**  
答：参见 [运维手册 §6](./operations.md#6-文件存储模式local--minio) 与 [管理员手册 §8](./admin-manual.md#8-文件存储切换local--minio)。简单说：`deploy/.env` 里设 `CRMS_STORAGE_TYPE=minio` + 4 个 MinIO 凭证，重启 `crms-app`。

**问：本地启动后端连不上数据库。**  
答：确认 Docker 中 MySQL 已启动、`deploy/.env` 中账号密码与 `application-local.yml` 一致、端口 3306 未被占用。

## 验收与测试

**问：自动化验收脚本失败。**  
答：阅读 [验收指南](./acceptance.md) 中「契约对齐提示」；确认后端已启动且账号密码正确（改过密码用 `ACCEPT_PASS`）。

---

## 仍无法解决

收集：**操作时间、账号角色、请求 URL、浏览器控制台与后端错误码/traceId**（界面或 JSON 中），联系研发或运维并附 [操作日志](./operations.md) 中说明的审计查询方式。
